
# Python Mini Tools — Project Description

**Features**
1. Number Guessing Game
2. Word Frequency Analyzer

**Scoring rule:** The game starts with 100 points. Each valid incorrect guess reduces the score by 10 points, with a minimum score of zero. The game counts valid guesses and ends when the player guesses correctly.

**Word analysis:** The analyzer reads a text file using a `with` statement, converts words to lowercase, counts their frequency using `collections.Counter`, and displays the ten most common words.

**Python concepts used:** `random`, functions, loops, conditional statements, dictionaries, exception handling, regular expressions, file handling, and sorting by frequency.

**Files submitted:** `mini_tools.py` and `sample.txt`.

**Testing:** Test guesses of 1 and 100, invalid input, a missing file, and an empty text file.
